Программа производит расчёт на основании метода предельных состояний.   
====== Как пользоваться ======
Откройте файл parameters.txt и измените значения параметров на нужные вам значения.
Обратите внимание вам нужно выбрать принципиальную схему расчёта которая будет соответствовать вашей схеме конструкции. Т.е. напротив слова scheme = strut <--- вот сюда вписать одну из доступных схем.
Доступные схемы это либо console — свободностоящая шпунтина просто забитая в землю; либо strut — схема с распоркой на выбранной вами высоте; либо frame   — с прямоугольной обвязкой;  либо ring — с круговой обвязкой.
ВАЖНО!  напротив слова scheme = strut <--- вот сюда следует вписать точное обозначение вашей схемы! Т.е. либо console, либо strut, либо frame, либо ring. Не ошибитесь, иначе программа не будет работать. Поэтому лучше скопировать)
Остальные параметры установлены базовыми. Их можете менять в зависимости от ваших условий, просто заменяя базовые числа на ваши.
После того как занесли все параметры в файл parameters.txt, сохраните его и закройте.
Запустите файл Sheet_piling_calculator_2.
В той папке где находится файл Sheet_piling_calculator_2.exe result.txt будет создан файл с результатами расчёта.
Если вам нужно рассчитать новый проект. Измените параметры в файле parameters.txt и запустите программу заново. При этом файл result.txt будет перезаписан. Поэтому если вам нужны предыдущие данные скопируйте их в другой файл.
